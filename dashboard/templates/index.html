DSCG 三层防御结构

完整防御默认启用以下三层；L1 不新增模型调用，审计重试为 0，完成提示关闭。L2 编译权限后只向规划器展示已授权工具，候选执行前仍复核。明确要求执行指定文件、唯一邮件或任务网页时，先经监控读取，再编译完整有效任务；普通返回不能扩权。网页可关闭工具视图与明确任务来源展开；宿主任务 profile 仅通过 API 配置，未配置时沿用原授权策略。

第一层 · 工具返回隔离
外部结果与错误正文原消息保留给日志与审计
有限字段投影 / 来源封装月支出省略交易备注；不适用则保留原文
主模型规划视图无关注入用概述，必要引用保留
L1 投影仅支持原生银行月支出任务，不认证事实；必要分析与引用保留原文。L2 授权只来自可信任务与宿主策略
第二层 · 可信任务工具授权
有效用户任务明确委托的文件先准备读取
编译授权与工具视图冻结目录 · 新用户任务替换授权
候选权限前置检查非法混合批次整体拒绝
规划和 L3 使用同一有效任务；未授权工具即使被模型编造仍拒绝，目录变化不自动扩权

真实工具执行结果返回主模型
工具反馈经 L1 返回主模型；重规划的新候选重新经过 L2、L3 和票据校验。对象与数据范围仍存在缺口。
已生效 · L1 输出规则
概述无关注入，保留必要引用

原始事实、正文与错误保留给审计和日志。日常摘要或发送任务以概述说明被忽略的无关指令，避免复述攻击目标；明确分析、安全报告与必要引用仍可保留原文。这是软规划提示，不是最终输出过滤。

已生效 · 审计输入
保留有界相关任务证据

最多 8 条当前任务相关调用与返回共享 8,192 字符，调用参数、遗漏和截断均显式记录；文件大小比较保留完整元数据。事实仍不可信；候选工具的宿主描述最多 512 字符。

已生效 · L3 外发审查
正文与目的地一并核对

安全提醒夹带无关攻击链接也可能偏离任务；必要来源链接和显式安全分析仍可保留。有效公开无外发读取沿用免审。已授权且无 sink 的读取，原 Monitor 仍可能覆盖有效 deny；不确定或错误阻断。

L3 可选算法路由
off 仍保留动作审计

off 关闭新增选择性路由；shadow 只观察，selective 须满足硬条件与兼容校准。目前默认 off，无可部署阈值；模式和 artifact 仅有 API/CLI 入口。网页不提供路由控制。关闭整个 L3 使用“动作审计”开关。

任务来源边界
完整任务展开，超限失败

仅支持有限的明确执行句式；正文最多 1,536 字符，完整有效任务最多 2,048 字符，序列化返回最多 16,384 字符。总结、普通返回与递归委托不升级权限；用户确认后文件被污染的情形不在此功能范围。

当前能力边界
工具级约束

对象、目的地、参数与数据权限尚未强制约束，最终纯文本回答不经动作审计。默认仍授予有效读取工具；宿主 profile 可选且无默认业务规则。单次观测不能证明安全增益或成本节省，原研究闸门状态不变。
