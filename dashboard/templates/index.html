DSCG 三层防御结构

完整防御默认启用以下三层；L1 不新增模型调用，审计重试为 0，完成提示关闭。L2 编译权限后只向规划器展示已授权工具，候选执行前仍复核。明确要求执行任务文件时，先经监控读取，再编译完整有效任务；普通返回不能扩权。网页可关闭工具视图与任务文件展开；宿主任务 profile 仅通过 API 配置，未配置时沿用原授权策略。

第一层 · 工具返回隔离
外部结果与错误正文原消息保留给日志与审计
宿主来源封装短标记 · 可逆转义 · 零模型调用
主模型规划视图事实可用，正文不能授予权限
L1 是提示防护，不能认证事实；L2 授权只来自真实用户任务与宿主策略
第二层 · 可信任务工具授权
有效用户任务明确委托的文件先准备读取
编译授权与工具视图冻结目录 · 新用户任务替换授权
候选权限前置检查非法混合批次整体拒绝
规划和 L3 使用同一有效任务；未授权工具即使被模型编造仍拒绝，目录变化不自动扩权
第三层 · 当前动作语义审计
当前候选动作工具、参数与有限动作历史

审计提供风险判断，最终执行仍由原授权与监控器仲裁
执行基础设施 · Monitor / 一次性票据
统一执行仲裁白名单、元数据、审计与动作状态
一次性执行许可绑定原调用 · 使用后失效
