NewFrame 双层漏斗防御架构
用户请求 User Prompt
→
🛡️ 权限沙箱 物理漏斗: 动态白名单 工具级过滤
→
🔍 安全校验器 语义漏斗: 意图对齐审计 组合攻击检测
→
⚙️ 工具执行 ToolsExecutor
→
✅ 安全响应 返回到 LLM / 用户
第一层 - 物理漏斗
  • 读写分离: 自动放行读操作
  • 意图解析: LLM 推理所需工具
  • 动态白名单: 仅允许必要工具
  • 违规拦截: 伪造报错触发纠错
第二层 - 语义漏斗
  • 写操作预检: 跳过纯读操作
  • 全局动作流审计
  • 意图对齐判定
  • 逻辑滥用 / 数据泄露检测
安全保障
  • 事前拦截 → 事中审计 → 事后监控
  • 组合攻击防御
  • Token 开销可控
  • 消融实验支持
