# v3.6.3 发版说明

2026-11-02。在 v3.6.2 基础上把 P0 也设为默认：**不需要任何环境变量或新参数**，`experiments/run_benchmark.py` 跑出来就是"P1 + P0"形态。

## 1. 本版改了什么

| 项 | v3.6.2 | **v3.6.3** | 消融方式 |
| --- | --- | --- | --- |
| P1 L2 紧凑输入 | 默认开 | 默认开 | `DSCG_AUTHORIZATION_INPUT=v2` |
| P0 审计证据补全 | 默认关 | **默认开** | `DSCG_AUDIT_PRESENTATION=v2` |
| 记录版本 | `DSCG_v3.6.2` | `DSCG_v3.6.3` | — |

- P0 打开后的默认行为：证据包原本会截断时，启用一次上限 32,768 字符的完整呈现（小包仍是 8,192）；候选参数字符串上限 512→8,192；超过上限仍标 `content_truncated`／`arguments_truncated`，仍然 `deny/abstain` 阻断。
- 两个形态都写进配置身份与 `run_manifest.json`，跨形态不会被 `--reuse` 复用。
- 审计默认包变小还是变大：变大（`bundle_sha256` 固定测试已按新默认更新）。

## 2. 为什么要默认打开

1. 你的测试只走 `experiments/run_benchmark.py`，不该再记着加环境变量；上一条规则已写入 `AGENTS.md`（改动默认生效、不新增参数）。
2. deepseek-flash 在 workspace 的 clean 回归正是被 L3 abstain 拦下的合法写入：v3.6.2（P0 关）仍是 33/40，其中 u31/u34/u36/u37 依旧被拦；P0 开的历史证据是定向 20 键 12/20→17/20、5 键×3 重复 9/15→15/15。
3. 代价已知：qwen 上 P0 约 +5.7% token（审计 +89%、生成 −25%）；需要省 token 的对照可显式 `DSCG_AUDIT_PRESENTATION=v2`。

## 3. 测试命令（只要这一条）

```bash
conda run -n ipi python -B -m experiments.run_benchmark \
  --suites workspace \
  --model-config config/models.deepseek.local.toml \
  --name ds_v363 --progress
```

- 加 `--clean` 就是无攻击对照；加 `--attack important_instructions` 就只跑一种攻击。
- 不需要 `--prompt-profile`、不需要 `--audit-router-mode`（默认 shadow）、不需要任何环境变量。
- 结果：`results/benchmarks/agentdojo/deepseek-flash/ds_v363/<attack>/workspace/`。

核对形态：

```bash
python -c "import json;c=json.load(open('results/benchmarks/agentdojo/deepseek-flash/ds_v363/run_manifest.json'))['common'];print(c['main_model']['model_id'],c['defense_version'],c['authorization_input'],c['audit_presentation'])"
# 期望：deepseek-flash DSCG_v3.6.3 v3 v3
```

## 4. 边界

- `run_benchmark` 是**全量**入口：只接受 `--suites` 限定场景，`--task-manifest` 不能裁剪任务（会报 "full benchmark requires all registered task IDs"）。要裁任务请用 `run_partial_benchmark`。
- 全量 workspace = 40 用户 × 14 注入 × 3 攻击 = 1680 计分键，跑之前先确认时间预算。
- P0 会展示更长的未受信返回，带尾部注入的键要单独看 `attack_success`，不能只看 TSR。
- 本轮离线：16 失败/35 错误/13 跳过，与 ca7739f 基线失败集合逐条一致；`node --test tests/*.cjs` 54/54；冒烟 run 记录 `DSCG_v3.6.3 / v3 / v3`。
