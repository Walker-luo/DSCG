# v3.7 发版说明

2026-11-03。v3.7 = **v3.6.3 的输入形态定版**：不新增机制、不改评分，只是把两处输入形态作为默认并固定版本标识。`static-task-v354` 提示字节未变。

## 1. 相对 v3.6 的实质变化

| 项 | v3.6 | **v3.7** | 消融 |
| --- | --- | --- | --- |
| L2 工具编译输入 | 冗长 JSON + 冗余字段名 | **紧凑 JSON，去掉可由 `parameters` 推出的字段名** | `DSCG_AUTHORIZATION_INPUT=v2` |
| L3 审计输入 | 证据按 8,192 字符截断；候选参数 512 | **会截断时一次 32,768 字符完整呈现；候选参数 8,192** | `DSCG_AUDIT_PRESENTATION=v2` |
| 版本标识 | `DSCG_v3.5.4` | `DSCG_v3.7` | — |

- 两者都写进配置身份与 `run_manifest.json`（`authorization_input`、`audit_presentation`），跨形态不会被 `--reuse` 复用。
- 工具集合、完整描述、参数 schema、权限校验、执行顺序、评分、原生调用顺序都不变；审计仍可 `deny/abstain` 阻断，超限仍标截断。

## 3. 测试命令

不需要任何环境变量或新参数：

```bash
conda run -n ipi python -B -m experiments.run_benchmark \
  --suites workspace banking slack travel \
  --model-config config/models.local.toml \
  --name v37_run --progress
```

- 无攻击对照加 `--clean`；单一攻击用 `--attack important_instructions`。
- deepseek 换 `--model-config config/models.deepseek.local.toml`。
- `run_benchmark` 是全量入口，只能用 `--suites` 限场景；要裁任务请用 `run_partial_benchmark --task-manifest`。

核对形态：

```bash
python -c "import json;c=json.load(open('results/benchmarks/agentdojo/qwen3.7-flash/v37_run/run_manifest.json'))['common'];print(c['main_model']['model_id'],c['defense_version'],c['authorization_input'],c['audit_presentation'])"
# qwen3.7-flash DSCG_v3.7 v3 v3
```

## 4. 边界

- clean 的 ASR 不适用；攻击批 ASR=0 只代表本批 1946 个键，不等于普遍安全。
- P0 会展示更长的未受信返回，尾部注入需单独看 ASR。
- 离线：16 失败/35 错误/13 跳过（与 ca7739f 基线失败集合逐条一致）、`node --test tests/*.cjs` 54/54。
- 旧结果仍记原版本名（`DSCG_v3.5.4`／`v3.6.1`／`v3.6.2`／`v3.6.3`），不重标为 v3.7。
