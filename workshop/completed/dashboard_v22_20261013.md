# Dashboard v2.2 显示同步与验收

用户要求参考当前 `docs/framework_updates.md` 与 README 优化 Dashboard。已同步 **three-layer-l2-v2.2**，本阶段只修改页面、展示逻辑和版本元数据出口，不修改防御引擎、配置机制或默认值。

## 交付行为

- 页面初始标签和 `/api/config` 从引擎 `FRAMEWORK_VERSION` 读取版本；前端使用服务端元数据，去掉旧v1/v2固定标签。AgentDojo v1.2另标为基准版本。历史运行概览继续取保存的版本，缺失保持未记录。
- L1开关、预览、架构图说明日常无关注入使用概述，必要分析/安全报告/引用保留；L3说明外发同时检查正文和目的地。原文不删除，最终回答没有新增硬过滤或独立审计。
- 普通预览按有效工具视图/前置/L3开关更新；明确任务文件分支只在L2及展开开关有效时展示准备读取、完整有效任务和一次完整业务编译。关闭L2和原生baseline隐藏该分支。V2风格说明保留新版目录复核，不能精确重现历史V2。
- 架构图补齐任务文件字符边界、读取deny例外、默认读取策略与可选宿主profile，以及API/CLI纯算法路由的实际状态。网页不新增router/artifact控件，不启用选择性免审。
- 保存结果区分L3开关与off/shadow/selective模式；off仍保留L3。L2 trace覆盖与L1/路由覆盖并列；明确 `cost_comparison_ready=false` 时标出已记录成本不能直接代表全程或节省比例。没有该标记不主动推定成本可比。
- 桌面与390px窄屏布局保留原配色/组件，长版本可换行，委托分支纵向排列；既有历史分析下载、多指标分图和颜色映射代码保持。
