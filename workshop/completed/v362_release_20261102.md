# v3.6.2 发版说明

2026-11-02。v3.6 之上的输入形态版本，默认只启用 P1；P0 为按需开关。不新增机制、不改评分，`static-task-v354` 提示字节未变。

## 1. 本版改了什么

| 项 | 默认 | 开关 | 内容 |
| --- | --- | --- | --- |
| **P1** L2 工具编译输入 | **开启** `authorization_input=v3` | `DSCG_AUTHORIZATION_INPUT=v2` 回到旧输入 | 紧凑 JSON 分隔符；去掉可由 `parameters.properties` 推出的 `native_argument_names`。工具集合、完整描述、参数类型／必填／默认／枚举、自动读取分类不变；宿主目录、权限校验、执行 schema 不变 |
| **P0** L3 审计输入 | 关闭 `audit_presentation=v2` | `DSCG_AUDIT_PRESENTATION=v3` 开启 | 证据会截断时启用一次上限 32,768 字符的完整呈现（小包仍 8,192）；候选参数字符串上限 512→8,192；超限仍标截断 |
| 版本 | `DSCG_v3.6.2` | — | `framework_version_for_profile('static-task-v354')` 现返回 `DSCG_v3.6.2`；`static-task-v361`→`DSCG_v3.6.1` 与 `static-task-v352`→`DSCG_v3.5.3` 不变 |
| 身份 | — | — | `authorization_input` 与 `audit_presentation` 进 router 配置哈希与 `dscg_optimization_config`；跨形态的旧缓存不会被 `--reuse` 复用 |

## 2. 证据（详见 P0/P1 报告）

- **P1**：L2 每键 token −16.7%～−18%（`authorization_tools` 17.3k→14.0k、26.1k→21.1k），`authorization_intents` 不变；判定与对照同噪声级。
- **P0**（仅作开关）：有 block 的 20 键 12/20→17/20、5 键×3 重复 9/15→15/15、block 2→0；无 block 的 60 键持平（54→52，3 修 5 退为抽样噪声），代价 token +5.7%（审计 +89%）。
- 离线：`unittest discover -s tests` 16 失败/35 错误/13 跳过，与 ca7739f 基线失败集合逐条一致；`node --test tests/*.cjs` 54/54。

## 3. 测试命令

约定：**本版默认已是 P1**，无需任何环境变量；**P0 只在需要时**加 `DSCG_AUDIT_PRESENTATION=v3`。全部命令在仓库根执行，结果写到 `workshop/artifacts/<YYYYMMDD>_<task>/results`，避免污染 `results/`。

### 3.1 干净基线（无攻击，workspace）

```bash
mkdir -p workshop/artifacts/20261102_ws_clean
conda run -n ipi python -B -m experiments.run_partial_benchmark \
  --suites workspace --clean --audit-router-mode shadow \
  --results-dir workshop/artifacts/20261102_ws_clean/results --name v362_clean
```

### 3.2 三种典型攻击（workspace，全量用户 × 全部注入）

```bash
export D=workshop/artifacts/20261102_ws_attack
for A in ignore_previous important_instructions tool_knowledge; do
  conda run -n ipi python -B -m experiments.run_partial_benchmark \
    --suites workspace --attack "$A" --audit-router-mode shadow \
    --results-dir "$D/results" --name "v362_$A"
done
```

### 3.3 打开 P0（只需在命令前加变量）

```bash
export D=workshop/artifacts/20261102_ws_p0
DSCG_AUDIT_PRESENTATION=v3 conda run -n ipi python -B -m experiments.run_partial_benchmark \
  --suites workspace --attack important_instructions --audit-router-mode shadow \
  --results-dir "$D/results" --name v362_p0_ii
```

### 3.4 只跑指定任务（定向用例，替代全量）

先导出模板再裁剪，`user_task_ids`／`injection_task_ids` 就是网格：

```bash
conda run -n ipi python -B -c "
import json,sys; sys.path.insert(0,'.')
from experiments.common.partial_controls import make_task_manifest
m=make_task_manifest('full')
m['suites']={'workspace':{'user_task_ids':['user_task_31','user_task_34','user_task_36','user_task_37'],
                          'injection_task_ids':['injection_task_0','injection_task_4','injection_task_10']}}
m['selection_rule']='targeted: workspace 写入类失败键'
json.dump(m,open('/tmp/targeted.json','w'),ensure_ascii=False,indent=1)
"
conda run -n ipi python -B -m experiments.run_partial_benchmark \
  --suites workspace --attack important_instructions --task-manifest /tmp/targeted.json \
  --audit-router-mode shadow --results-dir workshop/artifacts/20261102_targeted/results --name v362_targeted
```

### 3.5 用 deepseek-flash 跑（把模型换成 deepseek）

先写一份 deepseek 的模型配置（`config/models.local.toml` 里已有 `[providers.deepseek]` 段）：

```bash
cat > config/models.deepseek.toml <<'TOML'
[main]
provider = "deepseek"
model_id = "deepseek-flash"

[security]
provider = "deepseek"
model_id = "deepseek-flash"
TOML

DSCG_AUDIT_PRESENTATION=v3 conda run -n ipi python -B -m experiments.run_partial_benchmark \
  --suites workspace --attack important_instructions --audit-router-mode shadow \
  --model-config config/models.deepseek.toml \
  --results-dir workshop/artifacts/20261102_ds_ws/results --name ds_v362_p0_ii
```

跑完先核对身份再读分数：

```bash
python -c "import json;c=json.load(open('workshop/artifacts/20261102_ds_ws/results/agentdojo/deepseek-flash/ds_v362_p0_ii/run_manifest.json'))['common'];print(c['main_model']['model_id'], c.get('defense_version'), c.get('authorization_input'), c.get('audit_presentation'))"
```

> 现行 `AGENTS.md` 把在线评测限定在 qwen3.7-flash；用 deepseek 跑属于你自己指定的例外，跑前请确认这条规则是否要同步修改。

### 3.6 结果怎么看

```bash
R=workshop/artifacts/20261102_ws_attack/results/agentdojo/qwen3.7-flash   # <backend>/<model>/<name>/
cat $R/v362_important_instructions/summary.md          # 紧凑摘要 + 失败索引
python -c "import json;c=json.load(open('$R/v362_important_instructions/run_manifest.json'))['common'];print(c['defense_version'], c['authorization_input'], c['audit_presentation'])"
```

`run_manifest.json` 的 `common` 会写明 `defense_version=DSCG_v3.6.2`、`authorization_input=v3`、`audit_presentation=v2|v3`、`prompt_profile=static-task-v354`，可据此确认每一批到底用了哪个形态（本轮冒烟已核对：默认批 `v3/v2`、开 P0 的批 `v3/v3`）。

## 4. 注意

- P0 会放大未受信返回的展示量，带"尾部注入"的键要单独看 ASR，不能只看 TSR。
- 不要用 `--reuse` 跨形态复用：身份已绑定，跨形态会被拒绝，属预期。
- 本版未改 `results/` 下任何历史结果；新运行按 `<backend>/<model>/<name>/` 布局落盘。
